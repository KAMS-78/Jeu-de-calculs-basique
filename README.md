# Jeu de calculs basique

Ce projet est un petit jeu en ligne de commande développé en **Pascal**. Le programme génère des opérations mathématiques aléatoires (additions, soustractions, multiplications, divisions) et demande à l'utilisateur de trouver la bonne réponse.

## Fonctionnalités
*   Génération d'opérations aléatoires.
*   Vérification des réponses de l'utilisateur.
*   Système de points ou de niveaux (si tu en as un).
*   Interface simple dans le terminal.

## Comment lancer le programme
1. Téléchargez ou clonez ce dépôt.
2. Ouvrez le fichier `jeu de calcul.pas` dans un environnement de développement Pascal (comme Free Pascal / Lazarus ou Turbo Pascal).
3. Compilez et exécutez le code.

## Langage utilisé
*   Pascal
